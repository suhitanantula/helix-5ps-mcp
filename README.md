# Helix 5Ps MCP

An open, no-login [Model Context Protocol](https://modelcontextprotocol.io) server for the **5Ps of Loop Design**: Perceive → Perform → Portfolio → Pause/Promote → Progress. It's from Suhit Anantula's work on strategy × design × AI.

**Status: scoping.** No code yet. See [docs/scope.md](docs/scope.md).

## Planned tools (6, read-only, deterministic)
| Tool | Purpose |
|---|---|
| `explain_5ps` | Overview of the loop and each P |
| `diagnose_5ps` | Which P do I need? Routes a problem to a P, with reasons |
| `apply_5ps` | Question set + output template for one P (or the whole loop) |
| `list_5ps_variants` | Loop, multi-agent, rhizomatic, population: names and one-liners |
| `get_5ps_variant` | Teaser for a form: when to use it, its shape, first steps |
| `compare_5ps_variants` | Side-by-side fit of 2–4 forms for a situation |

No accounts, no stored inputs. Advanced forms (multi-agent, rhizomatic, population) appear as teasers. The full methods come through Helix.
