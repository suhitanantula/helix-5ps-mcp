# 5Ps variants

| Variant | One-liner |
|---|---|
| loop | Perceive → Perform → Portfolio → Pause/Promote → Progress — the core public loop. |
| multi_agent | Five specialised agents keep cycling through the same loop. |
| rhizomatic | Any P can connect to any other. Rupture is allowed; there is no forced centre. |
| population | Several diverse trajectories run in parallel. You stay the reward model. |

Advanced forms (multi-agent, rhizomatic, population) appear as teasers. The full methods come through Helix.
