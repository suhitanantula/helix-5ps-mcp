# Multi-agent (teaser)

Companions are later forms of the same loop — not extra tools, and not five P installs. Same five capacities. Different organisation.

**What it is:** Five specialised agents keep cycling through the same loop.

**Why it works:** One pass is not enough when the landscape is wide. The agents interrupt each other until the map is fuller.

**When to use:** When a single pass through the loop is not enough and the landscape is wide.

**Shape:** Five specialised agents, same five capacities, cycling and interrupting each other.

**First steps:**
1. Use the core loop until it is already working for you.
2. Assign one agent-focus per capacity (Perceive, Perform, Portfolio, Pause/Promote, Progress).
3. Let agents interrupt each other until the map is fuller — then Pause/Promote with human judgement.
